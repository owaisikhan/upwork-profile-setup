# Fiverr profile setup

Fiverr is not Upwork with a different logo. On Upwork you go to clients; on
Fiverr clients come to you through **search**. That changes everything: your
titles are SEO, your gig images matter more than your text, and your first
week's job is to get any order at all so the algorithm has data on you.

## Linked accounts

Link **GitHub**. Fiverr shows it on your profile and for a developer it is the
strongest trust signal you have — 24 public repos with real commit history beats
any badge. Do the pre-launch GitHub cleanup in `../profile/05-launch-plan.md`
first; a linked GitHub full of `test` and `helloWorld` works against you.

## The three things that actually decide whether you sell

1. **Gig images.** More than half the decision. A buyer scanning search results
   sees a thumbnail and a price, and reads the description only if the thumbnail
   earns it. Details in `03-gig-images.md`.
2. **Your first 3 reviews.** A gig with zero reviews converts terribly no matter
   how good it is. Everything in the launch plan is aimed at getting past that.
3. **Response time.** Fiverr publishes it on your profile and weights it in
   search. Install the app and reply within an hour, always. This is free
   ranking and most sellers throw it away.

## Fiverr vs Upwork — run both, differently

| | Upwork | Fiverr |
|---|---|---|
| How work arrives | You send proposals | Buyers find your gigs |
| Cost to you | Connects per proposal | Free to list |
| Platform fee | 10% | **20%** |
| Effort shape | Ongoing daily grind | Front-loaded setup, then passive |
| Best for | Larger custom projects | Defined, repeatable packages |
| Time to first order | 2–5 weeks of daily proposals | 1–6 weeks, mostly waiting |

**Price Fiverr higher than Upwork.** The fee is double. A gig at $100 nets you
$80; the same job on Upwork at $100 nets $90. Every price in `02-gigs.md`
already accounts for this — don't discount them back down.

Run both. Fiverr costs you nothing to leave standing, so set it up once
properly and let it work while you're sending Upwork proposals.
